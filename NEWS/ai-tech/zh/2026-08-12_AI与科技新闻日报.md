## 二、大模型、安全与组织变动

### 2. 「Stolen Thoughts」研究：加密推理链可被跨模型解密，公开日志泄露密钥与密码（安全）
**摘要：** 由 MATS、ELLIS Tübingen、MPI-IS、Snyk 等 8 名研究者组成的团队发布论文「Stealing Reasoning Traces from Proprietary LLM APIs」（arXiv 2608.09867，8 月 10 日提交），并上线演示站点 stolen-thoughts.com。研究指出 Anthropic、OpenAI、Google 等厂商将 chain-of-thought 以加密块返回客户端，这些块可在同厂商不同会话、用户乃至强弱模型间复用；攻击者将强模型的加密推理注入弱模型并 jailbreak，即可迫使弱模型明文转录 frontier 模型的完整思考过程，成本约两次 API 调用。团队从 GitHub 与 Hugging Face 采集 6,708 条公开 agent 轨迹，解码 315,320 个推理块，回收 704 条隐私信息（含 62 个 API 密钥、33 个密码）；并发现 Kimi K3 与 Claude Opus 4.8 的推理过程存在高度相似实例。GIGAZINE、《The Decoder》等于 8 月 12 日跟进。

**链接：**

- [arXiv — Stealing Reasoning Traces from Proprietary LLM APIs](https://arxiv.org/abs/2608.09867v1)
- [Stolen Thoughts — 项目主页](https://stolen-thoughts.com/)
- [The Decoder — Leaked passwords in ChatGPT's hidden reasoning](https://the-decoder.com/but-marinade-and-leaked-passwords-are-what-researchers-found-in-chatgpts-hidden-reasoning/)

**简评：** 隐藏推理本为防蒸馏，客户端可移植加密块反而成了「推理侧信道」——反蒸馏与 Agent 日志公开正在互相拆台。

### 5. NVIDIA 开源 Nemotron 3.5 Lightning：30B MoE、3B 激活，面向常驻 Agent 执行层（开源）
**摘要：** NVIDIA 8 月 11 日发布 Nemotron 3.5 Lightning，为 30B 总参数、3B 激活的混合 MoE 模型（Mamba-2 + MoE + Attention），上下文最长 100 万 token，面向长期运行的 autonomous agent 与子 Agent 工作负载；官方称推理速度可达同类开源模型的约 4 倍，智能水平对标 gpt-oss-120b 量级。权重以 OpenMDW-1.1 许可在 Hugging Face 开放 BF16 与 NVFP4 检查点，并配套 NemoClaw 开源 Agent 安全与管理栈；SGLang 同日宣布 Day-0 推理支持。Artificial Analysis 评测称其 Terminal-Bench v2.1 得分 24%，约为前代 Nemotron 3 Nano 的 3 倍。

**链接：**

- [NVIDIA Technical Blog — Nemotron 3.5 Lightning for long-running agents](https://developer.nvidia.com/blog/nvidia-nemotron-3-5-lightning-delivers-fast-accurate-specialized-task-execution-for-long-running-agents/)
- [Hugging Face — NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4)

**简评：** 芯片厂亲自下场做 Agent「工蜂模型」——开源小 MoE + NVFP4 是把推理栈与硬件绑定的标准打法。
