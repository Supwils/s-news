## 一、大模型与产品

### 1. Anthropic Claude 全球宕机约 3 小时，Opus 5 / Fable 5 等多模型报错（基础设施）
**摘要：** 8月24日，Anthropic 旗下 Claude 平台出现全球性服务中断。官方状态页显示，公司于 UTC 05:06 开始调查 Mythos 5、Fable 5、Opus 5 与 Opus 4.8 等模型的「elevated errors」，约 20 分钟后确认已定位原因并着手修复；至 UTC 08:30 宣布问题已完全解决，累计影响约 3 小时 24 分钟。claude.ai、Claude API、Claude Code 与 Cowork 均受影响，Claude Console 与政府版未中断。用户报告 529 Overloaded 与超时；Downdetector 显示美国超 1300 条、印度超 180 条投诉。这是 Anthropic 8 月以来多起稳定性事件中的最新一起。

**链接：**

- [Claude Status — Elevated errors for multiple models (Aug 24)](https://status.claude.com/)
- [The Next Web — Claude outage hits multiple models again](https://thenextweb.com/news/claude-outage-multiple-models)

**简评：** 当 Claude Code 成为开发者默认工具链，多模型同时报错会把「算力紧张」从财报脚注变成产品 SLA 危机。

### 2. Thomson Reuters 发布自有 LLM「Thomson 1.0」，以 Westlaw 等专有数据训练（产品）
**摘要：** 8月24日，Thomson Reuters（纳斯达克/多伦多：TRI）正式发布首个自研大语言模型 Thomson 1.0，基于 Qwen 3.5 等开源基座，在 Westlaw、Practical Law、Checkpoint 与 Reuters 等专有内容上做对齐与继续训练。公司称过去两年投入约 4000 万美元（含人才与算力），最终训练 run 约 45 万美元；首版将部署于 CoCounsel Legal 的 Tabular Analysis 结构化文档审阅功能，并计划向法律与税务产品线扩展。Thomson 同步在 Hugging Face 发布小规模 open-weight 版本供学术与非商业验证；外部学者评测称其在多项法律任务上可与部分前沿闭源模型比肩。

**链接：**

- [Thomson Reuters — Launch of Thomson proprietary LLM (Aug 24)](https://www.newswire.ca/news-releases/thomson-reuters-leverages-its-world-class-data-assets-to-launch-its-own-frontier-model-804511989.html)
- [Artificial Lawyer — TR Launches Thomson 1.0 – Its Own LLM](https://www.artificiallawyer.com/2026/08/24/tr-launches-thomson-1-0-its-own-llm/)

**简评：** 4000 万美元换「自有模型 + 自有数据闭环」，是垂直行业对通用 frontier 推理账单的一次主权化反击。

### 3. 神秘模型 Ox Alpha 免费上线 OpenRouter，社区猜测与智谱 GLM 有关（开源/匿名发布）
**摘要：** 8 月下旬，匿名大模型 Ox Alpha（OpenRouter ID：stealth/ox-alpha）在 OpenRouter 与 OpenCode 等平台以免费、104 万上下文、多模态能力上线，引发开发者实测热潮。MarsBit 等 8月24日报道，社区传播最广的 DeepSWE 小样本测试中 Ox Alpha 通过率约 80%，高于 Claude Fable 5（65%）与 GPT-5.6 Sol（52%）；多家实测称其推理链与 GLM-5.3 极为接近，猜测可能源自智谱 GLM 系列升级版，但官方未公布开发者与参数规模。OpenRouter 称每日约 100T token 服务容量，OpenCode 亦提供近「不限量」免费额度。

**链接：**

- [MarsBit — 神秘「牛来」模型 Ox Alpha 刷屏](https://news.marsbit.co/20260824084311651685.html)
- [OpenRouter — stealth/ox-alpha model page](https://openrouter.ai/stealth/ox-alpha)

**简评：** 匿名免费 frontier 级模型再次证明：在开放路由生态里，「谁做的」往往比「跑分多少」更晚才被揭晓。

### 8. 清华–沃顿团队借 GPT-5.6 Sol Pro 证明梯度下降纯步长调度收敛下界（研究）
